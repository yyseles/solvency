# 偿付能力分析平台（C-ROSS 二期）

纯静态前端，展示保险行业 C-ROSS 二期偿付能力数据：最低资本 / 实际资本分解、行业与公司趋势、全行业概览，并支持数据导出 / 导入与生成可转发单文件网页。

## 使用
- 根目录 `index.html` 直接打开，或部署到任意静态托管（GitHub Pages / Netlify 等）。
- 页面内「数据」按钮：导出 / 导入数据 JSON、导出自带数据的可转发网页。
- `偿付能力分析平台_可转发.html` 为单文件自包含版本，可独立转发。

## 结构
- `index.html` / `app.js`：页面与逻辑
- `data.js`：各保险公司偿付能力数据
- `reg_industry.js`：监管披露行业平均数
- `echarts.min.js`：图表库
- `dist/`：同步分发目录
- `_build_standalone.py`：构建单文件网页
